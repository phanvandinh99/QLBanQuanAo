Common VNPay Issues & Solutions

Possible causes:

  • Hash secret mismatch between your config and VNPay settings
  • Parameters not sorted correctly during hash calculation
  • URL encoding/decoding issues
  • VNPay API version mismatch (should use 2.0.0)

Solutions:

  • Check hash secret in config.py matches VNPay dashboard
  • Verify all parameters are URL decoded before hashing
  • Check application logs for detailed validation information

Possible causes:

  • Order invoice format incompatible with VNPay (too long or contains invalid characters)
  • Order not saved to database before redirect to VNPay
  • Database connection issues during order creation

Solutions:

  • Ensure invoice is alphanumeric and max 34 characters
  • Check order creation flow in application logs
  • Verify database connectivity

Possible causes:

  • Amount calculation error in cart/order processing
  • Amount format issues (should be VND * 100)
  • Discount calculation errors

Solutions:

  • Verify amount calculation logic
  • Check for floating point precision issues
  • Test with different cart configurations

Log Files

To debug VNPay issues, check the application logs. All VNPay operations are logged with detailed information including:

  • Payment URL creation parameters
  • Return/IPN request parameters
  • Signature validation details
  • Order status updates

Log levels:

  • INFO: Successful operations and key events
  • WARNING: Non-critical issues (failed payments, etc.)
  • ERROR: Critical errors requiring attention
  • DEBUG: Detailed validation information (enable for troubleshooting)
